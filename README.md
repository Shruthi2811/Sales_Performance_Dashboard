# Sales Performance Dashboard

An interactive sales analytics dashboard built with Python, Pandas, DuckDB, Streamlit, and Altair using the UCI Online Retail dataset.

This project explores overall sales performance, customer behavior, product trends, and country-level ordering patterns through a business-focused dashboard. It is designed as a portfolio project to demonstrate end-to-end analytics work: data cleaning, metric design, SQL-style analysis, and dashboard storytelling.

## Project Overview

The goal of this project is to analyze retail transaction data and turn it into a clear, decision-oriented dashboard. The app highlights:

- revenue and order trends over time
- customer retention and segmentation patterns
- product performance and basket behavior
- country-level order size and average order value comparisons

The dashboard is organized into four sections:

1. Executive Overview  
2. Customer Insights  
3. Product Insights  
4. Country Insights
